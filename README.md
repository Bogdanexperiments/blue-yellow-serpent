# Сине-жёлтый змей

**Язык программирования:** Python

**Назначение:** Лабораторные работы, скрипты, учебные проекты и будущие разработки на Python.

> Сине-жёлтый змей спокойно переживает отсутствие `.venv` в Git.

## Структура каталогов

```text
Labs/
Projects/<project>/src/
Projects/<project>/requirements.txt
Experiments/
Documentation/
```

Реальные файлы лабораторных и проектов добавляются в соответствующие каталоги. Для нескольких C-программ, Python-скриптов или веб-сайтов заводи отдельную папку проекта.

## Запуск и сборка

Для каждого проекта создавай отдельное виртуальное окружение; оно не хранится в Git.
```sh
cd Projects/<project>
python3 -m venv .venv
source .venv/bin/activate  # macOS / Linux
python -m pip install -r requirements.txt  # если файл зависимостей есть
python src/main.py
```
В Windows PowerShell активируй окружение командой `.venv\Scripts\Activate.ps1`.

## Учебные работы и проекты

Пока реальные работы в репозитории не добавлены. По мере готовности указывай здесь название, краткую цель и ссылку на папку каждой работы или проекта. Демонстрационные заглушки не используются.

## Будущие дополнения

Добавляй новые лабораторные работы и самостоятельные проекты в соответствующие каталоги. Для каждого самостоятельного проекта сохраняй локальные инструкции по запуску, сборке и зависимостям.
